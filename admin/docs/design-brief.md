# Base Admin — UI/UX 设计 Brief

## 项目概述

通用后台管理系统的 Admin 端前端，基于 Vue 3 + Element Plus。
目标：**世界级后台管理系统**——不是 Element Plus 默认外观，而是在其基础上打造有辨识度的、现代的、克制的高端视觉。

参考方向：Linear、Vercel Dashboard、Raycast、Stripe Dashboard —— 干净、克制、信息密度高、动效精致。

---

## 设计原则

1. **Less is more** — 减少视觉噪音，留白充足，信息层级清晰
2. **Neutral base, vivid accent** — 大面积中性色（灰白），小面积强调色（蓝）
3. **Micro-interactions** — 每一个点击、悬浮、切换都有精致的反馈
4. **Consistent density** — 表格紧凑但不拥挤，表单宽松但不浪费
5. **Dark mode ready** — 颜色体系用 CSS Variables，随时切换

## 页面清单 & 设计要点

### 1. 登录页

**布局**：左右分栏
- 左侧：品牌展示区（渐变背景 + Logo + Slogan + 装饰图形）
- 右侧：登录表单（居中卡片）

**表单元素**：
- 用户名输入框（placeholder: "用户名或邮箱"）
- 密码输入框（带显示/隐藏切换）
- 记住我（Checkbox）
- 登录按钮（主色，宽度 100%，带 loading 状态）

**交互**：
- 输入框聚焦：底部边框变主色 + 微微上浮
- 登录按钮 loading：文字消失 → spinner + "登录中..."
- 登录成功：按钮变绿 ✓ → 页面淡出 → 跳转

**风格**：简洁、商务、不花哨。不要插画，用几何线条或渐变色块。

### 2. 主布局（后台框架）

```
┌──────────────────────────────────────────────────┐
│ Header（60px）                                    │
│ [☰] [面包屑]                    [消息🔔] [头像 ▾] │
├────────┬─────────────────────────────────────────┤
│        │ TagsView（36px，标签栏）                  │
│ Sidebar│ ┌──────────────────────────────────────┐ │
│ (220px)│ │                                      │ │
│        │ │          AppMain（内容区）             │ │
│ 深色   │ │          padding: 20px              │ │
│ 背景   │ │          背景: #F8FAFC              │ │
│        │ │                                      │ │
│        │ └──────────────────────────────────────┘ │
└────────┴─────────────────────────────────────────┘
```

**Sidebar**：
- 深色背景（#111827），和内容区形成强烈对比
- Logo 区域顶部（折叠时只显示图标）
- 菜单项高度 44px，图标 + 文字
- 选中态：左侧 3px 蓝色竖线 + 文字变白 + 背景微亮
- 悬浮态：背景微亮 rgba(255,255,255,0.05)
- 展开/折叠动画 280ms

**Header**：
- 白色背景 + 底部 1px 阴影
- 左侧：折叠按钮 + 面包屑
- 右侧：消息铃铛（带未读红点） + 用户头像下拉（个人中心/退出登录）

**TagsView**：
- 标签栏，可滚动
- 当前标签高亮（主色底+白字）
- 右键菜单：关闭当前/关闭其他/关闭全部
- is_affix 的标签不可关闭（如仪表盘）

### 4. CRUD 列表页（通用模板）

**布局**：
```
┌──────────────────────────────────────────────┐
│ 搜索区域（白色卡片，可折叠）                     │
│ [关键词输入] [状态下拉] [日期范围] [搜索] [重置] │
├──────────────────────────────────────────────┤
│ 工具栏                                        │
│ [+ 新增] [删除] [导出]           共 X 条       │
├──────────────────────────────────────────────┤
│ 表格（白色卡片）                                │
│ ☐ │ ID │ 用户名 │ 昵称 │ 状态 │ 创建时间 │ 操作│
│ ☐ │ 1  │ admin  │ 管理员│ ● 正常│ 2026-..│ 编辑│
│ ☐ │ 2  │ zhang  │ 张三  │ ● 正常│ 2026-..│ 编辑│
├──────────────────────────────────────────────┤
│ [◀ 1 2 3 ... ▶]                  每页 20 条 ▾ │
└──────────────────────────────────────────────┘
```

**表格设计要点**：
- 行高 52px（紧凑但不拥挤）
- 表头：灰色背景（#F9FAFB），字号 13px，字重 500
- 斑马纹：奇偶行微弱色差
- 悬浮行：背景变 #F8FAFC
- 操作列：文字按钮（蓝色编辑/红色删除），不用 icon 按钮
- 状态列：用彩色圆点 + 文字（● 正常 / ● 禁用）

**搜索区域**：
- 默认展开，超过一行时可折叠
- 输入框统一 width，排成网格
- 搜索/重置按钮靠右

### 5. 表单弹窗

**弹窗**：
- 宽度 560px（简单表单）/ 720px（复杂表单）
- 顶部：标题 + 关闭按钮
- 中间：表单内容（label 在左，input 在右，label 宽度 100px）
- 底部：取消 + 确定按钮（靠右）
- 打开动画：scale(0.95) + opacity(0) → scale(1) + opacity(1)，250ms
- 遮罩：rgba(0,0,0,0.4)，backdrop-filter: blur(4px)

**表单项**：
- 每行一个字段（简单），或两列布局（字段多时）
- 必填标记：红色 *
- 输入框聚焦：边框变主色
- 错误提示：红色文字在输入框下方

---

### 6. 菜单管理（树形表格）

- 缩进展示层级关系
- 图标列：展示菜单的 icon
- 类型列：用标签区分（目录/菜单/按钮）
- 排序：支持拖拽排序（可选）

## 交互细节

| 场景 | 交互 |
|------|------|
| 按钮点击 | scale(0.97) → scale(1)，50ms |
| 按钮 loading | 文字 → spinner + "处理中..." |
| 删除确认 | ElMessageBox 二次确认，红色按钮 |
| 表格加载 | 骨架屏（Skeleton），不用 loading spinner |
| 页面切换 | 内容区 fade + translateY(10px)，200ms |
| 空状态 | 居中图标 + "暂无数据" + 操作按钮 |
| 成功提示 | ElMessage success，3 秒自动关闭 |
| 错误提示 | ElMessage error，5 秒自动关闭 |
| 搜索 | 输入后 Enter 或点击搜索按钮触发，不做实时搜索 |
| 批量删除 | 选中行后按钮激活，未选中时按钮禁用 |

## 响应式

| 断点 | 布局 |
