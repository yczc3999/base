## 1. 目标与用户价值

在声明 `v2_0002` 的 control/artifact/outbox 表之前，先建立唯一的 `trading` ORM 类型与 mixin
内核，防止后续模型各自发明主键、时间、精确数值、hash、外部 ID 和 optimistic-version
写法。本任务不建表、不创建 migration。

## 2. 已确认决策与依赖

1. PostgreSQL schema 固定 `trading`；Base 旧表仍在 `public`，不得改变现有 18 表 metadata。
2. 高频内部主键用 `BIGINT GENERATED BY DEFAULT AS IDENTITY`。
3. 所有业务时间是 timezone-aware `TIMESTAMPTZ`；禁止 naive timestamp。
4. base-unit 精确数值是 `NUMERIC(38,0)` 且 `asdecimal=True`；hash 与外部 ID 使用 `C`
   collation；不得用 float。
5. mixin 只声明 ORM/DDL，不做 I/O、commit、状态转换或动态扫描。
6. 依赖：`WP-01A-01-r2` 已接受；Alembic head 保持 `b1000001`。

## 4. 实现合同

### 4.1 `constants.py`

只导出 `TRADING_SCHEMA = "trading"`。不得放状态枚举、配置、表名或策略常量。

### 4.2 `types.py`

导出无共享可变状态的 SQLAlchemy type factory：

- `utc_timestamp_type()` → `DateTime(timezone=True)`；
- `base_unit_type()` → `Numeric(38, 0, asdecimal=True)`；
- `sha256_type()` → `String(64, collation="C")`；
- `external_id_type()` → `Text(collation="C")`。

每次调用返回独立 type instance；不得读取 env/DB，不得包含价格 scale 等尚未冻结的类型。

### 4.3 `mixins.py`

- `BigIntIdentityMixin`：`id` 为 non-null `BigInteger + Identity(always=False) + primary_key`；
- `CreatedAtMixin`：`created_at` 为 non-null timezone-aware timestamp，`server_default=now()`；
- `TimestampMixin`：继承 created-at 并增加 non-null `updated_at`，server default 与 ORM update
  expression 均为 `now()`；
- `OptimisticVersionMixin`：non-null BIGINT `version`，Python/server 初值均为 1，并通过
  `__mapper_args__["version_id_col"]` 启用 SQLAlchemy optimistic locking。

不得把 `updated_at/version` 放进 append-only 表；mixin 只是显式选择的能力，不自动注入所有表。

### 4.4 Import boundary

- `models/trading/__init__.py` 显式导出上述常量、factory、mixin；不得动态扫描模块。
- `app/models/__init__.py` 显式导入并导出 `trading` package，使后续 metadata imports 有唯一入口；
  重复 import 不得改变 `Base.metadata.tables` 或产生 DB/文件/网络 I/O。

## 5. 必测证据

1. 四个 type factory 的 precision/scale/timezone/collation/asdecimal 完全匹配，且重复调用不是
   同一实例。
2. 用测试内 synthetic models 编译 PostgreSQL DDL，证明 identity、TIMESTAMPTZ、
   `NUMERIC(38,0)`、`COLLATE "C"` 和 version default 正确；不得真的创建生产表。
3. Mapper 的 `version_id_col` 精确指向 synthetic model 的 `version`；Python 默认与 server
   default 都是 1。
4. import/reload 零 I/O、无 metadata duplicate；任务前后 Base metadata 表集合仍恰好原 18 张。
5. `alembic heads` 仍只有 `b1000001`；不存在 `trading` schema/revision/生产表。
